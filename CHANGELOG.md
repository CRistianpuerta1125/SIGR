# Changelog — SIGR

Todos los cambios relevantes de este proyecto se documentan en este archivo.

## [1.0.0-baseline] - 2026-11-07
### Added
- Módulo de autenticación de usuarios con control de acceso por rol.
- Módulo de menú digital con operaciones CRUD de platos y categorías.
- Módulo de registro y seguimiento de pedidos en tiempo real.
- Módulo de reservas por fecha y hora.
- Módulo de cierre de caja y reportes de ventas diarios.
- Documentación inicial: README, modelo de datos y manual de despliegue.
- Estructura de carpetas y convenciones de código definidas.

Esta versión constituye la **línea base** del proyecto: primer hito estable
sobre el cual se aplicará el control de cambios.
